### tasks

Open the task picker with executable task files from the project and Janissary. Choosing a task inserts its command into the command line without running it.

**Usage**

`tasks`

**Use cases**

- Browse available tasks and insert one into the command bar.
- Find project or built-in workflows without locating their files manually.

**Examples**

- `tasks` opens the task picker.
- `Ctrl+A` opens the same picker from the keyboard.
