### acp

Send a prompt to the core OpenCode ACP session and read its streaming response in the ACP panel.

**Usage**

`acp <prompt>`

`acp reset`

**Use cases**

- Ask the current tab's ACP agent a question.
- Start a fresh ACP session when you want to clear its prior context.

**Examples**

- `acp Explain this failing test` sends a prompt to the ACP agent.
- `acp reset` starts a fresh ACP session.
