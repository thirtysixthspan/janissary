### clear

Clear the current tab's output log. In a shell tab, bare `clear` is sent to zsh to clear the terminal instead; use `/clear` to clear the application output log.

**Usage**

`clear`

`/clear`

**Use cases**

- Remove old output from the current tab.
- Clear a shell terminal with the ordinary shell command.

**Examples**

- `clear` clears the output log on a non-shell tab.
- `/clear` clears the application output log from a shell tab.
