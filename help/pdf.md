### pdf

Open a PDF in the bundled PDF tab. It accepts the same paths and wildcards as `open`. The PDF tab has no command bar. To use your PDF application instead, run `open external <path>`.

**Usage**

`pdf <path>`

**Use cases**

- Read a PDF without leaving the application.
- Open several matching PDF files from a wildcard.

**Examples**

- `pdf report.pdf` opens a PDF tab.
- `pdf reports/*.pdf` opens the matching PDF files.
