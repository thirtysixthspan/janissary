### clipboard

Open the clipboard-history popup, which lists text copied inside Janissary during this session. Selecting an item pastes it at the cursor; it does not run the text.

**Usage**

`clip`

Type `clip` alone in a command bar and press Enter. `clipboard` is the name of this help page; typing it does not open the popup.

**Use cases**

- Reuse text copied earlier in the session.
- Paste a saved command into the command bar and review it before running.

**Examples**

- `clip` opens clipboard history.
- `Ctrl+Shift+V` or `Cmd+Shift+V` opens the same popup from the keyboard.
- **Paste from clipboard…** in the right-click menu opens it too.

**Notes**

- Copies made in other applications are not listed. Empty and whitespace-only copies are skipped.
- On a tab with no command line, such as a markdown or image tab, the popup does not appear, but the keyboard stays with it until you press `Escape`.
