### clipboard

Open the clipboard-history popup, which lists items copied during this session. Selecting an item pastes it at the cursor; it does not run the text.

**Usage**

`clipboard`

**Use cases**

- Reuse text copied earlier in the session.
- Paste a saved command into the command bar and review it before running.

**Examples**

- `clipboard` opens clipboard history.
- `Ctrl+Shift+V` opens the same popup from the keyboard.
