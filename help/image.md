### image

Open an image in the bundled image tab. It accepts the same paths and wildcards as `open`. If the image is already open, its tab is focused instead. To use your OS image viewer instead, run `image external <path>`.

**Usage**

`image <path>`

**Use cases**

- View an image without leaving the application.
- Open several matching images from a wildcard.

**Examples**

- `image diagram.png` opens an image tab.
- `image screenshots/*.png` opens the matching images.
