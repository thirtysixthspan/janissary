### sql

Open a database browser with table filtering, sorting, paging, editing, export, and a SQL console. Bare `sql` opens the most recently used database.

**Usage**

`sql [<name>]`

`sql [<name>] left`

`sql [<name>] right`

**Use cases**

- Browse and edit tables in a SQLite database.
- Open the most recently used database or select one by name.
- Dock the database browser beside another tab.

**Examples**

- `sql` opens the most recently used database.
- `sql inventory` opens the database named `inventory`.
- `sql inventory right` docks that database browser on the right.
