### profile

Launch a saved profile, save the current session as a profile, list saved profiles, or validate one.

**Usage**

`profile launch [<name>]`

`profile save <name>`

`profile list`

`profile validate [name]`

**Use cases**

- Reopen a saved arrangement of tabs and settings.
- Save the current session for later.
- Check whether a saved profile is valid.

**Examples**

- `profile launch review` launches the profile named `review`.
- `profile save review` saves the current session as `review`.
- `profile list` opens the list of saved profiles.
