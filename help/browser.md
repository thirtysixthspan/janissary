### browser

Control a browser from the command bar. Open pages, navigate, inspect content, run an expression, capture a screenshot, or select a browser window.

**Usage**

`browser open <url>`

`browser goto <url>`

`browser content`

`browser eval <expression>`

`browser shot [name]`

`browser use <window-id>`

**Use cases**

- Open and inspect a web page while keeping the browser in the current session.
- Capture a screenshot or inspect the page's content.

**Examples**

- `browser open https://example.com` opens a page in the browser.
- `browser content` returns the current page content.
