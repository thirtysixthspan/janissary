### syntax

Set the syntax-highlighting theme used by every open editor and diff tab. Bare `syntax theme` opens a theme picker.

**Usage**

`syntax theme <name>`

`syntax theme`

**Use cases**

- Choose syntax colors that are comfortable to read.
- Preview available themes in the picker.

**Examples**

- `syntax theme nord` sets the syntax theme to `nord`.
- `syntax theme` opens the syntax theme picker.
