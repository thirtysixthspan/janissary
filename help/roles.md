### roles

Open the roles tab to review and edit each named role's ordered harness, model, and effort choices.

**Usage**

`roles`

**Use cases**

- Browse the available agent roles.
- Review the harness and model choices assigned to each role.
- Choose only enabled models from the catalog; use `models` to refresh or edit that catalog.
- Edit `~/.janissary/roles.json`, or a project's `.janissary/roles.json`, which replaces it entirely. Roles are a saved list only: nothing launches a harness from one.

**Examples**

- `roles` opens the roles tab.
- `roles left` is refused with `Usage: roles`.
- `models` opens the model catalog used by role choices.
