### launcher

Open or focus the launcher, optionally docking it on the right. Select a command row and click again to run it, or select a tab row to focus that tab.

**Usage**

`launcher`

`launcher right`

**Use cases**

- Find and run a command from the launcher.
- Find and focus a tab.

**Examples**

- `launcher` opens or focuses the launcher.
- `launcher right` opens or focuses the launcher in the right sidebar.
