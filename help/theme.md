### theme

Set the application's color theme. Bare `theme` opens a picker, and `theme sync` makes the syntax theme match the application theme when a matching syntax theme exists.

**Usage**

`theme <name>`

`theme`

`theme sync`

**Use cases**

- Change the color theme across the application window.
- Preview themes in the picker.
- Set the syntax theme to match the application theme.

**Examples**

- `theme light` applies the `light` application theme.
- `theme` opens the theme picker.
- `theme sync` matches the syntax theme to the application theme when possible.
