### audio

Queue an audio file in the single audio tab. Paths and wildcards work the same way as with `open`.

**Usage**

`audio <path>`

**Use cases**

- Play an audio file from the project.
- Queue several matching files with a wildcard.

**Examples**

- `audio recording.mp3` queues one audio file.
- `audio recordings/*.mp3` queues matching MP3 files.
