### newdir

Create a directory immediately. If the requested name is already taken, a free name is chosen; the parent directory must already exist.

**Usage**

`newdir <directory>`

**Use cases**

- Create a project directory without opening a terminal.
- Create a uniquely named directory when the preferred name may already exist.

**Examples**

- `newdir notes` creates a `notes` directory.
- `newdir src/components` creates a directory under `src` when that parent exists.
