### diff

Open the diff tab to review project changes, changes under one path, or a selected tab's workspace changes.

**Usage**

`diff`

`diff <path>`

`diff on <tab name>`

**Use cases**

- Review all project changes against HEAD.
- Focus the diff on one file or directory.
- Review changes in another tab's workspace.

**Examples**

- `diff` opens the project's changes against HEAD.
- `diff src` limits the diff to the `src` directory.
