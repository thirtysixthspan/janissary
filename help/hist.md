### hist

Open the command history picker. When `hist` is disabled in the Commands tab, the command and `Ctrl+R` are refused.

**Usage**

`hist`

**Use cases**

- Find and reuse a command entered earlier.
- Browse command history when the keyboard shortcut is unavailable.

**Examples**

- `hist` opens the command history picker.
- `Ctrl+R` opens the command history picker from a tab where the application owns that shortcut.
