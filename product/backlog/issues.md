* when creating a new file from the file navigator, the editor tab should open with a default file name of untitled.md, and that default name should show up in the tab label and in the metadata row. The name in the tab metadata label should be highlighted, have keyboard focus, and allow the file name to be changed, just as it is changed in the tab label. If the user hits enter, the new file name is accepted and the keyboard focus and keyboard input caret then goes to the top of the editor buffer. When the user hits escape, the default file name is used, even if charaters had been typed in the metadatabar, and the keyboard focus and keyboard input caret go to the top of the buffer.

* update the tooltip of the commit to origin button in the file navigator to specify the branch onto which the commit will go.

* add commit to origin icon to the editor tab metadata bar that will save the current file locally and commit the current file to origin on the current branch.

* use $workspace as a symbol to mean the workspace path in the metadata bar. for example: $workspace/research instead of /Users/anonymouscoward/dev/janissary/.janissary/workspace/research 
this should work on local and remote harnesses and agents.
