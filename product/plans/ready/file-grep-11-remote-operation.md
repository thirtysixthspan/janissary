Add no parse step, secondary timer, catch, local fallback or filesystem-port method.
- Import/register the descriptor in `src/remote/filesystem/operations.ts:32`, `READ_OPERATIONS`, and add a `grep-files` result decoder beside glob in `result-decoders.ts`. Preserve the generic exhaustive table and inferred result type. Reject missing/nonstring text, null and arrays with exactly `Invalid remote filesystem operation result.`; preserve string text verbatim, including empty text, diagnostics, no-match output and partial-result trailers. Follow the existing record-with-text convention rather than requiring an exact single-key object.
- Preserve `RemoteFileNavigators.request` and the unmodified central `refusedPaths`/`physicallyContainedPath` guards. An omitted path names no path for this guard; empty string is the root exception. A direct wire path of `.` or the absolute root is refused by existing containment. On the filesystem transport, central containment runs before run and can refuse an outside-resolving secret spelling before workspace lexical secret skipping or regex validation. Keep that guard intact. The later typed remote port's absolute-path check can likewise finish before run; local and far-side ACP calls use workspace order. Do not duplicate the matcher near side to manufacture identical precedence or bypass containment for grep. Unexpected synchronous throws and asynchronous workspace rejections become the existing error replies; do not convert them to no matches.
- Bump `REMOTE_PROTOCOL_VERSION` in `src/remote/protocol.ts:229` from 42 to 43 with the existing-style comment that older peers refuse the new operation. Update the literal assertion at `src/remote/protocol.test.ts:968`, `is 42`, to 43. Preserve the dynamic matching/newer/older handshake tests, including refusal of 42, and existing parked-peer version enforcement at `src/remote/serve-detach.ts:194`, `record.version`. - Keep `grep-files` out of `LONG_RUNNING` in `src/file-navigator/remote/port-requests.ts:39`; the ordinary request deadline stays 60,000 ms. The workspace entry owns its 30-second budget and preserves scan partial rows; this descriptor adds no cancellation/lifecycle mechanism.
