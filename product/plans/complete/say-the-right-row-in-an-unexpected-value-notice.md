# Say the right row in an unexpected-value notice

`outliers` in `src/visualizations/insights.ts` labelled its sentences with `labelOf(chart.table.rows[row.index])` and returned `row.index` — the table's own row, which is what the renderer means by a row. `unexpected` walked `values` instead: a compacted array of the measure's cells, with the rows that are not numbers dropped, so `index` there is a position among the values that were kept. It compared that position against the fences' table row numbers, labelled `table.rows[index]` with it, and pushed the position into the set it hands to the other detector.

- `rowsOf` in `src/visualizations/insights-statistics.ts` now returns each value beside the row it came from, and `numericValues` is the same rows without the positions. `Row` is a named type rather than a local one, because the value and the row it is about are the two halves of anything a notice claims.
- `unexpected` walks `rowsOf` and labels from `point.index`, so its rows are the table's rows, which is what the set handed to it holds and what `outliers` returns. One coordinate system, stated once.
- The order of the two checks is the other half of the finding. `total` was incremented before the already-spoken test, so a row the fences had named was counted as one the sentence was not making, and the "and N more" tail claimed findings the reader had already been given — the sawtooth case below said "and 1 more value" about the 9000 and the 10 named in the clause before it. A row already spoken for is now skipped before anything is counted, and the cap is checked after, so the count is exactly the findings that are not in the sentence and are not spoken elsewhere.

Two cases in `src/visualizations/insights.test.ts`, both of which fail against the previous indexing. The gapped series has a row empty in both the date and the measure, so the values after it are one position further on than the rows they came from: the notice named 2026-06-06 for a value measured on 2026-06-07, and said the 9000 twice under two dates because the two detectors disagreed about which row was the same row. The sawtooth pins the count, since a spike named by the fences and found again by the band is one spike, not a finding and a spare.
