## Proposed changes

- Export `GrepSearchTarget`, a success-only discriminated union, directly from `path-target.ts`. Both variants have `root`, the canonical absolute workspace root, and `prefix`, a root-relative directory string with forward slashes and no leading/trailing slash. The `directory` variant has `kind` equal to `directory` and `searchDir`, the canonical absolute selected directory; its prefix names that directory. The `file` variant has `kind` equal to `file` and `filePath`, the canonical absolute selected regular file; its prefix names the file's parent. The root directory and a file immediately in it both use the empty prefix. No other target path fields are needed; plan 7 derives a file's parent and basename with Node path helpers.
- Export `ResolvedGrepTarget` as the union of `GrepSearchTarget`, a skip variant with only `kind` equal to `skip`, and a failure variant with `kind` equal to `failure` and `text`, the complete diagnostic string. Export async `resolveGrepTarget(root, requestedPath)`: its first argument is a workspace-root string, its second is a required argument accepting a path string or `undefined`, and its promise resolves to `ResolvedGrepTarget`. Plan 8 returns failure text or formats empty rows for skip before passing a `GrepSearchTarget` to plan 7. Consumers import these defining exports directly from `./path-target.js`; do not duplicate the union, return formatted `(no matches)` here, or use null/undefined as another outcome.
- Use `.` when `requestedPath` is undefined, including for diagnostics on an unavailable default root. Otherwise retain the supplied string exactly for diagnostics; normalization must not turn `./missing/` into `missing`. Argument syntax validation belongs to plan 1, not this resolver.
- Run `checkLexicalPath(root, effectivePath)` before asynchronous target metadata. An absolute path, even one pointing inside the workspace, or a normalized parent escape returns failure text `Outside the workspace: <typed>.`. A lexical secret immediately returns skip, even when absent; do not probe it merely to choose a different diagnostic. Run this policy for omitted path and explicit `.` as well as named children.
- Canonicalize the root with asynchronous `realpath`, require that it is a directory, and perform subsequent component checks beneath that canonical root. The supplied root itself may be a safe symlink alias; neither that alias nor platform aliases above the root count as forbidden descendant links. Check the canonical root with `checkRealTarget(realRoot, realRoot)` so a workspace inside a literal or resolved home-secret anchor skips even when its ordinary-looking child is requested. Preserve existing policy semantics rather than extending the deny rules to arbitrary root basenames.
- Derive the normalized lexical root-relative target from the original root and effective path, then the expected absolute path beneath the canonical root. Inspect its descendant components with asynchronous `lstat`, root outward, retaining evidence of any ancestor or final symlink. Stop component inspection at the first link and proceed to full-target canonicalization for containment precedence; do not inspect deeper descendants through it. Every nonfinal ordinary component must be a directory. Root selection has no descendant components. Final-file `lstat` alone and canonical-path equality alone both miss ancestor links, including a link to its containing directory. Keep this component inspection in a private helper in the same module so failure and link evidence remain explicit without deeply nesting the resolver.
- Resolve the target with asynchronous `realpath` and call `checkRealTarget(realRoot, realTarget)` before selecting the retained link outcome. A resolvable real target outside the canonical root returns the exact outside diagnostic, even through a link; an in-root real secret returns skip. Policy checks and link inspection are metadata work only. Never open or read contents through the link to determine its outcome.
- When real resolution succeeds and policy allows it, any observed descendant link returns skip, including links to ordinary in-root files/directories and links back to the root. Also skip if the canonical target differs from the expected canonical-root-plus-normalized-relative path. Equality is an additional guard, not a replacement for component inspection.
- When a discovered final or ancestor link cannot resolve, return skip rather than `Path not found`, including a dangling named link, a dangling ancestor, and a missing child beneath an existing link. If no link was found, missing paths, a path through an ordinary file, inaccessible metadata, root canonicalization failure, or failed target `realpath`/`lstat` return failure text `Path not found: <typed>.`. Keep filesystem-error mapping within these metadata operations, without wrapping unrelated programming exceptions as successful no-match results.
- Classify only a link-free regular file or directory as success using `lstat` metadata. A FIFO or other nonregular named target returns skip without opening. Byte-size, binary, gitignore and include/exclude checks remain with plans 4/7; even an oversized named regular file first resolves as a file target here.
- Normalize output prefixes using native path operations before converting `path.sep` to forward slashes. Omitted path, `.`, and `./` produce the root directory and empty prefix. `./src`, `src/`, and `./src/` produce the selected directory and prefix `src`; `./src/a.ts` produces a file target with prefix `src`. Normalize contained dot segments consistently with `checkLexicalPath`; preserve the typed spelling only in diagnostics. This resolver does not construct candidate paths or strip the directory prefix from later output.
- Own no timers, handles, signal or deadline argument. Plan 8 wraps the whole `resolveGrepTarget` call in plan 5's `withDeadline` from `src/file-grep/deadline.ts`, using the same absolute deadline as discovery and scan. Pending metadata may settle after timeout; it never starts content I/O, listing, matching, transcript output or any publication here. Plan 8 must ignore its late result and must not await losing metadata before returning timeout. This consumer obligation adds no dependency from plan 6 to plan 5 and changes no shared listing API. Existing synchronous policy setup cannot be preempted by a timer; retain that practical limit without claiming OS metadata cancellation.

## Tests

Add colocated Vitest coverage in `src/file-grep/path-target.test.ts`, importing the three exported contracts directly from `./path-target.js`. Use real temporary fixtures for normal paths and links, scoped filesystem mocks for deterministic metadata failures, and a mocked `node:os` `homedir` pointing at a temporary home before policy runs. Restore mocks and remove fixtures after each case. These groups cover 42 distinct production behavior scenarios:

- Eight ordinary selections: omitted path, `.`, `./`, regular root file, ordinary directory, `./src`, `src/`, and `./src/`. Assert the discriminant, canonical absolute root/target and empty or normalized prefix, with no extra outcome sentinel.
- Three path-shape cases: a deeper selected directory, a nested file, and an ordinary child under a safe symlink alias supplied as root. Assert file prefix is the parent prefix and root alias never appears in canonical fields.
- Four containment refusals: absolute path inside, absolute path outside, normalized `..` escape, and a sibling whose name shares the root's prefix. Assert typed spelling and no asynchronous target metadata before refusal.
- Five lexical secrets: `.env`, nested `.env.local`, mixed-case `.ENV`, a multi-segment deny run, and a nonexistent secret. All skip before target metadata; retain plan 3's predicate semantics without extending them.
- Four home-root cases: default path and explicit `.` inside a literal home-secret anchor, then the same two inside the resolved location of a symlinked home-secret anchor. All skip; the tests use no actual user-home secret paths.
- Ten link/canonical cases: final in-root file link, final in-root directory link, in-root ancestor link, outside ancestor link, outside final link, ancestor link to its containing directory, dangling final link, dangling ancestor, missing child below a live link, and a mocked canonical-target mismatch with no observed link. Only resolvable outside targets produce the outside diagnostic; the others skip. Assert the mismatch and containing-directory cases cannot pass on equality or final metadata alone.
- Eight metadata/classification cases: missing ordinary target, child below ordinary file, FIFO, rejected root `realpath`, rejected ancestor `lstat`, rejected final `lstat`, rejected target `realpath`, and supplied root that is an ordinary file. The FIFO skips without an open; the other cases return the exact not-found text. Use `./missing/` in the missing case to pin typed diagnostics and mock permission errors instead of relying on host permission bits.

Across these cases assert that neither content reads nor listing/matching APIs are called. The outer timeout race and late-result rejection observation belong in plan 8's integration tests using plan 5's helper; do not import the future workspace entry or add a resolver timer to make this foundation's tests pass.
